## Mulai dari sini: rencana 8 minggu

Jika bahasa Inggris adalah titik lemahmu, prioritas utamanya adalah **kebiasaan harian yang konsisten**, bukan belajar maraton di akhir pekan. Rencana ini dirancang untuk 60–90 menit per hari.

> [!IMPORTANT]
> Meskipun LPDP dalam negeri 2026 tidak mewajibkan sertifikat bahasa Inggris, UI, UGM, dan ITB tetap mensyaratkannya untuk penerimaan. Bahasa Inggris tetap penentu lolos atau tidaknya kamu ke S2.

### Langkah 0: diagnosis (hari pertama)

1. Kerjakan **simulasi mini ELPT ITB / TOEFL ITP** atau **AcEPT UGM** di menu Simulasi.
2. Lihat bagian mana yang terendah: listening, structure, atau reading.
3. Catat skor awal. Ulangi simulasi mini setiap 2 minggu untuk melihat kemajuan.

| Target S2 | Patokan yang sering dipakai |
|---|---|
| UGM | AcEPT ≥ 209 (sebagian prodi 230) |
| ITB | ELPT ITB sesuai syarat (tercantum 77) |
| Kampus lain / umum | TOEFL ITP 450–500 |

> [!TIP]
> Skor terakhirmu sekitar 430 dan targetmu MBA/MM/Magister Teknik? Ikuti rencana 90 menit per hari di halaman [Jalur MBA & Teknik](#jalur) dan hitung selisih skormu di sana.

ETS memetakan skor TOEFL ITP ke level CEFR: sekitar 460 = B1 dan 543 = B2. Skor 500 berada di tengah level B1, yaitu sudah mampu memahami teks akademik sederhana.

## Strategi listening

- Baca pilihan jawaban **sebelum** audio diputar untuk menebak topik.
- Fokus pada kalimat pembicara kedua; jawaban biasanya ada di sana.
- Waspadai pilihan yang memakai kata **berbunyi sama** dengan audio; sering itu pengecoh.
- Pahami makna idiom, bukan arti per kata.

| Ungkapan | Makna |
|---|---|

| I wish | Hal itu tidak terjadi (sayangnya belum) |

| No wonder | Pantas saja |
| It's up to you | Terserah kamu |
| Count me in | Saya ikut |
| Under the weather | Sedang kurang sehat |
| A piece of cake | Sangat mudah |
| Hit the books | Belajar keras |
| Call it a day | Selesai untuk hari ini |
| Out of the question | Tidak mungkin |
| Take a rain check | Menunda ke lain waktu |
| On second thought | Setelah dipikir ulang |
| Why don't you … / How about … | Memberi saran |
| If I were you, I'd … | Memberi saran |

## Strategi structure dan written expression

Untuk soal structure, periksa berurutan: subjek ada? verb utama ada? butuh kata penghubung? ada inversi? paralel? Untuk written expression, cek delapan sumber kesalahan berikut dari yang paling sering keluar.

1. Kesesuaian subjek dan verb
2. Bentuk verb dan tenses
3. Kata benda tunggal/jamak
4. Bentuk kata (adjective, adverb, noun, verb)
5. Preposisi dan pasangan kata tetap
6. Kata ganti
7. Paralelisme
8. Perbandingan

## Strategi reading

| Tipe soal | Cara mengerjakan |
|---|---|
| Main idea / best title | Baca kalimat pertama setiap paragraf dan kalimat terakhir teks. Pilih yang mencakup semua paragraf |
| Detail ("According to the passage") | Cari kata kunci di teks, baca 1–2 kalimat di sekitarnya |
| Vocabulary in context | Ganti kata dengan setiap pilihan, pilih yang tidak mengubah makna kalimat |
| Reference ("it", "they" refers to) | Lihat kata benda sebelum kata ganti; cocokkan tunggal/jamak |
| Inference ("It can be inferred") | Jawaban tidak tertulis persis tetapi pasti benar berdasarkan teks |
| NOT / EXCEPT | Coret tiga pilihan yang ada di teks |
| Author's purpose / attitude | Perhatikan kata sifat dan kata penghubung (however, fortunately, unfortunately) |

## Membangun kosakata lebih cepat

Pelajari bagian kata. Satu akar kata membuka puluhan kata baru.

| Bagian | Arti | Contoh |
|---|---|---|
| un-, in-, im-, il-, ir- | tidak | unlikely, insufficient, impossible, illegal, irrelevant |
| dis-, mis- | tidak / salah | disagree, misinterpret |
| re- | kembali | revise, retain |
| pre-, post- | sebelum / sesudah | predict, postpone |
| inter-, trans- | antar / melintasi | interact, transform |
| sub-, super- | di bawah / di atas | subsequent, superficial |
| -tion, -ment, -ness, -ity | kata benda | contribution, requirement, awareness, capacity |
| -ive, -ous, -al, -able | kata sifat | innovative, numerous, crucial, sustainable |
| -ize, -ify | kata kerja | prioritize, clarify |
| -ly | kata keterangan | rapidly |
| bio / chron / geo | hidup / waktu / bumi | biology, chronic, geothermal |
| dict / scrib, script | berkata / menulis | predict, describe |
| port / tract / ject | membawa / menarik / melempar | transport, attract, reject |
| spect / vid, vis | melihat | perspective, evident, visible |

## Composing (khusus AcEPT)

Soal composing menguji kemampuan menyusun kalimat menjadi paragraf yang padu. Kuncinya adalah kata penghubung dan kata rujukan.

| Fungsi | Kata penghubung |
|---|---|
| Menambah | moreover, furthermore, in addition, also |
| Mempertentangkan | however, nevertheless, whereas, on the other hand |
| Sebab-akibat | therefore, consequently, as a result, thus |
| Memberi contoh | for example, for instance, such as |
| Urutan | first, next, then, after that, finally |
| Menyimpulkan | in conclusion, overall, in short |

Langkah menyusun paragraf: (1) cari kalimat topik yang paling umum dan tidak diawali kata rujukan; (2) kalimat dengan "this/they/it" harus setelah kalimat yang dirujuk; (3) kalimat dengan "as a result/finally" biasanya di akhir.
